# Mediatheque

## Description
Projet de gestion de médiathèque web permettant de gérer des bandes dessinées, des vinyles et des utilisateurs.

## Technologies utilisées
### Frontend
- React
- TypeScript
- Tailwind CSS
- Radix UI/Components
- Concurrent pour le thème sombre/dégradé

### Backend
- Node.js
- Express
- PostgreSQL
- JWT pour l'authentification

### Docker
- PostgreSQL dans un conteneur
- Backend Node.js dans un conteneur
- Frontend statique dans un conteneur Nginx

## Pour contribuer

### Prérequis
- Docker installed
- Git installed
- Node.js installed (version 16+)
